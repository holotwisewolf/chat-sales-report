# Sales Report & Analytics Dashboard 📊

An intelligent, interactive sales dashboard and report management application built with Node.js, Express, SQLite, and Google Gemini AI. Features real-time bento analytics, drag-and-drop report processing (PDF, Excel, Images), Excel-style interactive table data editing, custom print report builder, and conversational AI data analysis.

---

## Key Features

- **Interactive Bento Dashboard**: Key performance indicators, monthly trends, category revenue breakdown, channel rankings, and animated peer comparisons.
- **Smart Document Processing**: Upload sales reports (PDFs, Excel spreadsheets, or photos). Extracts retailer, period, counter sales, and SKU details automatically.
- **Excel-Style Spreadsheet Table**: Edit values in-place, drag column borders to adjust widths, sort, filter, and undo edits/deletions.
- **Chat with an AI**: Context-aware AI assistant powered by Google Gemini. Ask questions about your sales data, trends, or specific counters.
- **Live Gemini AI Insights**: Dynamic data observations generated by Gemini AI based on active retailer, counter, and category numbers.
- **Custom Print & PDF Generator**: Stepper modal to customize columns, font sizes, alignments, themes, and page pagination before printing or exporting to PDF.
- **Docker Support**: Containerized with Docker for seamless deployment across environments.

---

## Tech Stack

- **Backend**: Node.js, Express.js, SQLite (`better-sqlite3`)
- **AI Integration**: `@google/genai` (Google Gemini API)
- **Document Processing**: `pdf-parse`, `xlsx`
- **Frontend**: HTML5, Vanilla JavaScript, CSS3 (Modern Glassmorphism & Micro-animations)
- **Charts**: Custom SVG Line Graphs & Animated Bar Charts

## Prerequisites

- Node.js (v18 or higher)
- npm (v9 or higher)

## Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/holotwisewolf/chat-sales-report.git
   cd chat-sales-report
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set Environment Variables**:
   Create a `.env` file in the root directory (or export environment variables):
   ```env
   PORT=3000
   GEMINI_API_KEY=your_google_gemini_api_key_here
   ```

4. **Start the application**:
   ```bash
   npm start
   ```
   Open `http://localhost:3000` in your web browser.

---

## Running with Docker 🐳

1. **Build the Docker image**:
   ```bash
   docker build -t sales-dashboard .
   ```

2. **Run the Docker container**:
   ```bash
   docker run -d -p 3000:3000 -e GEMINI_API_KEY="your_api_key" --name sales-app sales-dashboard
   ```

3. **Access the application**:
   Navigate to `http://localhost:3000`.
